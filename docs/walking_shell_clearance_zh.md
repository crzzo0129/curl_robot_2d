# 二维行走姿态与弧壳缩短验证

更新日期：2026-07-28

## 1. 问题

二维模型此前只围绕 `compact` 滚动构型设计弧壳。虽然 `open` 直腿姿态没有
接触，但为了避免固定弧壳在关节处几何重叠，活动范围被收窄为：

| 关节 | 旧弧壳兼容范围 | 源模型建议安全范围 |
|---|---:|---:|
| 髋 | `[-1.12, 1.5708]` rad | `[-1.12, 2.41]` rad |
| 膝 | `[0, 2.69]` rad | `[-0.61, 2.69]` rad |

这等于让滚动外壳反过来限制未来行走模态，不符合双模态项目目标。本次修改以
恢复完整建议安全范围为约束，求解外壳端部所需的最小缩短量。

## 2. 行走检查姿态

模型新增 `walk` 关键帧：

| 量 | 数值 |
|---|---:|
| front hip / knee | 0.35 / 0.52 rad |
| rear hip / knee | 0.35 / 0.78 rad |
| root z | 0.308694 m |
| 前足位置 x/z | 0.101057 / 0.019950 m |
| 后足位置 x/z | -0.063904 / 0.031443 m |
| 后足离地间隙 | 11.493 mm |

该姿态表示前足支撑、后足摆动，只用于行走工作区和碰撞检查，不是固定行走
轨迹。静态 `mj_forward` 后自接触数量为 0，任意两段弧壳之间的最小表面
间隙为 40.639 mm。

## 3. 外壳修改

将“相邻共线杆件的弧壳端部表面间隙”从 2 mm 增加到 28 mm。对应几何为：

| 参数 | 修改前 | 修改后 |
|---|---:|---:|
| 每端裁剪角 | 7.2882° | 13.1350° |
| 单边弧壳覆盖角 | 57.4235° | 45.7301° |
| 覆盖角缩短比例 | 0 | 20.36% |
| 共线端部表面间隙 | 2 mm | 28 mm |

外壳半径、中心线接触圆半径、每边 capsule 数量和五条结构边长度均未改变。
因此 compact 的名义圆半径不变，但四个活动关节附近的圆周覆盖缺口增大。

## 4. 完整安全范围扫描

`scripts/analyze_walking_shell_clearance.py` 使用真实生成后的 capsule 几何，
对髋、膝建议安全范围各采样 1001 点。它显式计算父子刚体外壳间的距离，因为
MuJoCo 默认不会为直接父子 body 生成接触。

| 扫描 | 范围 | 最小外壳间隙 | 最坏角度 |
|---|---:|---:|---:|
| front hip | `[-1.12, 2.41]` rad | 2.370 mm | 2.410 rad |
| front knee | `[-0.61, 2.69]` rad | 9.820 mm | -0.610 rad |

前后链几何镜像，因此后腿具有相同的关节处间隙结论。修改后的
`shell_compatible_range` 已恢复为完整建议安全范围。

## 5. 对滚动基准的影响

把旧碰撞约束 CEM 控制器直接回放到缩短后的外壳模型，不重新搜索：

| 指标 | 旧 2 mm 外壳 | 新 28 mm 外壳 |
|---|---:|---:|
| 10 s 净滚动 | 9.914 圈 | 9.049 圈 |
| 水平位移 | 9.589 m | 8.831 m |
| 腾空比例 | 12.99% | 11.21% |
| 最长腾空 | 17 ms | 28 ms |
| 最大足间距 | 0.2081 m | 0.2085 m |
| 非允许接触比例 | 1.38% | 0.97% |
| 最大非允许穿透 | 0.459 mm | 0.608 mm |
| 最大足端软接触穿透 | 0.924 mm | 1.662 mm |
| 腿部交叉 | 0 | 0 |

未重训时圈数下降约 8.7%，但持续滚动和硬约束仍成立，说明缩短外壳没有破坏
滚动可行性。由于接触序列已经改变，旧 CEM 和当前云端 PPO 只能作为修改前
基准；新模型的正式 CEM/RL 结果必须重新搜索或训练。尤其是最大穿透有所
增加，后续重新搜索时需要继续保留现有穿透代价。

## 6. 结论

1. 常见弯膝行走姿态本身在旧模型中不碰撞；问题是旧外壳迫使关节工作区小于
   源模型建议安全范围。
2. 将共线端部间隙增至 28 mm，可在完整安全范围内保留至少 2.37 mm 外壳
   间隙。
3. 代价是单边圆弧覆盖减少约 20%，关节附近滚动接触更不连续。
4. 该折中保住了行走工作区，同时保留接近每秒一圈的旧控制器直接回放能力。
5. 旧控制器回放的最大穿透变大，当前结果只能证明可行性，不能取代重新优化。
6. 后续结构设计可研究关节护片、弹性搭接或随动外壳，以填补滚动圆周缺口，
   但不能重新封死行走关节范围。

## 7. 复现

```powershell
python -m scripts.generate_model
python -m scripts.inspect_model --keyframe walk
python -m scripts.analyze_walking_shell_clearance --samples 1001
python -m scripts.render_model --keyframe walk `
  --output-dir results/walking_shell_clearance
python -m unittest discover -s tests -v
```
