# 刚性滚动相位分析

## 1. 目的与假设

本分析使用现有的 `assets/curl_robot_2d.xml`，不创建第二个机器人模型。
四个内部关节始终保持 `compact` 关键帧角度，只扫描根节点的滚动相位
$\phi$。脚本只设置 `qpos` 并调用 `mj_forward`，不调用 `mj_step`，
因此重力不会通过有限 $K_p/K_d$ 或力矩上限压变形构型。

该分析回答理想刚性 compact 构型的几何和重力问题，暂不包含：

- 弧壳离散接触产生的冲击和能量损失；
- 摩擦和打滑；
- 关节柔顺变形；
- 电机能量输入；
- 外壳自身的质量和惯量。

## 2. 无滑动运动学

名义接触圆半径为

$$
R_c=0.1475476\ \mathrm{m}.
$$

正五边形中心到 Torso 中心线的距离为内切圆半径 $a$。令正的根节点
pitch 表示向 $+x$ 方向滚动，则理想圆心和根节点位置为

$$
x_c=R_c\phi,\qquad z_c=R_c,
$$

$$
x_{\mathrm{root}}=R_c\phi+a\sin\phi,
\qquad
z_{\mathrm{root}}=R_c+a\cos\phi.
$$

每个相位都通过 MuJoCo 正运动学重新计算各刚体质心和整体质心。

## 3. 计算量

设整体质心为 $(x_G,z_G)$，瞬时接触点为 $(x_c,0)$，总质量为
$m$，则：

$$
U=mgz_G,
$$

$$
\tau_g=mg(x_G-x_c).
$$

$\tau_g>0$ 表示重力推动正向滚动，$\tau_g<0$ 表示重力阻碍正向
滚动。脚本同时根据各 body 的质量、惯量和质心位置计算整体相对接触点的
转动惯量。

## 4. 当前参数结果

使用 361 个相位样本扫描一圈，得到：

| 指标 | 结果 |
|---|---:|
| 总质量 | 3.170 kg |
| 名义接触圆半径 | 0.147548 m |
| compact 质心相对圆心 $x$ 偏置 | 0.011877 m |
| compact 质心相对圆心 $z$ 偏置 | 0.072854 m |
| 质心偏心距 | 0.073816 m |
| 偏心距/接触半径 | 0.5003 |
| 最低质心高度 | 0.073732 m |
| 最高质心高度 | 0.221363 m |
| 势能峰谷差 | 4.5910 J |
| 最大重力矩幅值 | 2.2955 N·m |
| 圆心高度最大数值误差 | $2.8\times10^{-17}$ m |
| 偏心距峰峰数值误差 | $3.3\times10^{-16}$ m |

主要相位为：

| 相位事件 | 相位 |
|---|---:|
| 正向最大助推重力矩 | 80.741° |
| 最低势能稳定姿态 | 170.741° |
| 最大反向重力矩 | 260.741° |
| 最高势能姿态 | 350.741° |

当前 `compact` 初始相位为 $0^\circ$，它位于最高势能姿态之后约
$9.26^\circ$，初始重力矩为正。因此从静止释放时，重力会推动机器人
向前滚向 $170.741^\circ$ 附近。

整圈势能峰谷差虽然达到 4.5910 J，但 compact 初始状态已经比最低势能
状态高约 4.561 J。从 compact 到下一最高势能点只差约 0.030 J。若接触
完全无损，静止释放后的理论正向转折点约为 $341.482^\circ$；它仍不能
从静止越过下一势能峰。真实离散弧壳还会产生碰撞、弹跳和摩擦损失，因此
实际转折会更早。

## 5. 当前结论

1. 当前刚性构型是明显的偏心轮，质心偏心距约为滚动半径的一半。
2. compact 初始姿态接近势能峰，因此适合观察一次重力驱动的被动滚动。
3. 水平地面上的连续被动滚动不可能抵消耗散；至少需要初始能量、坡度或
   主动关节做功。
4. 下一步动态实验应重点测量一次滚动中的接触损失，而不只是重复判断质心
   是否偏心。
