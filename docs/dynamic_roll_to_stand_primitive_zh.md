# 高动态 Roll to Stand：任务定义

2026-09-06。本文记录新的实现目标，尚不代表环境改造、训练或 mesh 验证已经完成。

## 已确定的范围

- 滚动来源先使用 CEM reference，不依赖滚动 RL checkpoint。
- 训练使用 `rollingquad_2_primitive`；最终使用 `rollingquad_2` mesh 版本验证。
- 目标是从正在滚动的真实状态直接恢复足端支撑并稳定站立。
- 这是高动态恢复任务：不要求先停止滚动，也不规定制动、展开的先后顺序。
- 本阶段终点是 Stand。已有 Walking 作为后续接管技能；站稳是合理接口，但行走接管仍需单独回放验证。

## 连续控制约束

整条 primitive 回放采用同一个物理模型：reference 滚动 → learned Roll to Stand → 持续站稳。只切换控制器，不切换碰撞几何，不覆盖机器人姿态，不清零速度，不抬高机器人解除穿透。

reference 应使用 primitive 对应的控制器文件，并将实际路径、内容哈希、物理配置和滚动参数写入数据来源记录。复用 residual 环境时，必须明确采用零 residual、完整 reference 权重，且确认没有额外动作项；不能把这种运行标记成 RL 教师。

先检查 reference 自身能在所选物理配置下持续滚动，再收集初态。初态保留 qpos、qvel、ctrl、仿真时间及快照格式要求的其他状态。控制历史按目标策略观测定义构建；不能把 reference 的内部变量当作同名策略历史直接复制。

接管后策略拥有全部 12 个关节的位置目标权限，受真实关节限位、伺服与力矩上限约束。动作平滑作为代价和诊断，不用强制慢插值替代高动态恢复。

## 学习目标

使用一个恢复任务和一个连续站稳计数器。策略从第一步即可同时展开、调整姿态和转移支撑；没有必须先通过的低速制动门槛。

训练初期可复用站立附近的恢复课程，再逐步加入真实 reference 滚动快照。阶段难度依据实际姿态、角速度、线速度和接触分布判断，不能把滚动圈数直接等同于速度。最终覆盖完整滚动相位，并按来源轨迹划分训练集和验证集。

奖励设计以足端支撑、直立、高度与最终低速的联合质量为核心，配合恢复进展、成功奖励及动作变化、冲击、滑移和执行器代价。最终低速收益应与站立质量绑定，避免奖励倒地静止。允许恢复早期正常壳体接地；稳定站立必须无非足端地面支撑。恢复早期不套用行走任务的姿态和接触终止规则。

初版建议沿用现有站立姿态、速度、高度和足端接触阈值作为候选标准，把连续满足时长设为 1 s，再做额外 2 s 持续站立验证。这些时长是待验证的实验设置，不是已经证明的成功门槛。不能只在短暂经过站姿的瞬间终止并记成功。

## primitive 与 mesh 验证

primitive 训练前核对足端几何、站立关键帧、关节顺序、质量惯性和执行器配置。保持所选模型的接触定义，不为了通过行走形态检查而删除壳体碰撞。

mesh 验证中从 reset 开始就使用 mesh：先在 mesh 上运行同一 reference，再从实际到达状态切换同一 Roll to Stand 策略。不得在接管时换模型，也不得直接把 primitive 的接触缓存交给 mesh。

分别报告 reference 在 mesh 上的滚动成功率，以及有效滚动初态上的恢复成功率。若 reference 自身不能持续滚动，先定位来源问题，不能将其全部算成过渡策略失败。额外的跨模型状态迁移测试必须单列，不能代替完整链路验证。

## 当前代码需要修改的位置

- `config_transition_3d.py`：新增明确的动态 Roll to Stand 配置，支持 primitive；保留旧课程行为作为对照。
- `environment_transition_3d.py`：新增不依赖 BRAKE → DEPLOY 门控的恢复路径，终点改为连续站稳；继续保留切换时的物理状态。
- `reward_transition_3d.py`：提供动态恢复奖励，避免强制先降速和过早惩罚正常壳体接地。
- `collect_transition_roll_snapshots.py`：现有入口要求 residual checkpoint 且限制 mesh，需新增显式 reference 来源路径并记录 provenance。
- 形态检查与快照元数据：审核 primitive 兼容性；不同几何的快照保持严格区分。
- 增加同模型 reference → 恢复策略 → 持续站稳评估入口，分别在 primitive 和 mesh 运行。

## 验收输出

按滚动相位、实际角速度和初态来源报告成功率、恢复时间、持续站立结果、最大倾斜、接触冲击、力矩峰值、关节限位与滑移。力矩和接触峰值应在物理子步采样，不能用控制边界采样声称全程峰值。

结果分开标记：配置/接口检查通过、primitive 实际训练与闭环评估通过、mesh 完整链路验证通过。未运行的阶段不得标记完成。
