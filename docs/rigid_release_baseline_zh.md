# 刚性 compact 动态释放基准

## 1. 实验目的

刚性相位分析给出的无损理论正向转折点为 $341.482^\circ$。本实验使用
同一个 `curl_robot_2d.xml`，测量当前 MuJoCo 接触模型中从 compact
零初速度释放后的实际运动，并量化理论与动态仿真之间的差异。

本实验不复制机器人模型。XML 中的四个 compact joint equality constraint
默认关闭；脚本运行时通过 `data.eq_active` 开启约束，同时：

- 关闭全部 actuator，避免位置伺服注入或吸收能量；
- 将 DOF damping 设为零，避免把人工关节阻尼计入接触损失；
- 保持重力、摩擦、弧壳和接触求解器参数不变；
- 验证四个内部关节的最大锁定误差。

## 2. 基准配置

| 参数 | 数值 |
|---|---:|
| 初始姿态 | compact |
| 初始速度 | 0 |
| 仿真时长 | 5.0 s |
| 时间步长 | 0.002 s |
| 地面坡度 | 0° |
| 摩擦系数 | 0.8 |
| 弧壳离散 | 6 capsule/边 |
| actuator | 关闭 |
| DOF damping | 关闭 |
| 内部关节 | 运行时 equality lock |

当前弧壳离散只是一种仿真实现。实体机器人可以通过 3D 打印或其他制造方式
得到连续圆弧，因此 capsule 数量不作为主要实体结构变量。本基准的能量损失
是“当前 MuJoCo 接触实现”的结果，不能直接等同于连续实体外壳的损失。

## 3. 结果

| 指标 | 结果 |
|---|---:|
| 无损理论转折相位 | 341.482° |
| 实际最大相位 | 284.700° |
| 相位缺口 | 56.782° |
| 到最大相位的能量损失 | 1.3436 J |
| 损失/整圈势能峰谷差 | 29.3% |
| 达到最大相位的时间 | 1.430 s |
| 最大正向角速度 | 11.888 rad/s |
| 最大反向角速度 | -10.102 rad/s |
| 总腾空时间 | 0.098 s |
| 最长连续腾空时间 | 0.010 s |
| 最大同时地面接触数 | 6 |
| 最大总法向力 | 226.0 N |
| 最大总法向力/机器人重量 | 7.27 |
| 最大单接触法向力 | 113.0 N |
| 最大接触滑移速度 | 0.0400 m/s |
| 接触期间平均力加权滑移 | 0.00317 m/s |
| 最大关节锁定误差 | 0.000796° |

机器人第一次向前滚动在 1.43 s 达到 $284.70^\circ$，随后反向摆回，并
继续围绕最低势能姿态进行幅度逐渐减小的往复摆动。5 s 内没有越过下一势能
峰，也没有完成整圈滚动。

## 4. 解释

最大关节锁定误差不足 $0.001^\circ$，因此本次结果满足刚性 compact
假设，实际转折提前不是关节被重力压变形造成的。

滑移速度整体较小，但运动中出现：

- 最高约为自重 7.27 倍的瞬时总法向力；
- 多次短时腾空；
- 接触数量快速切换；
- 总机械能呈阶梯式下降。

这些现象表明当前动态损失与碰撞和接触切换密切相关。不过本实验尚未把
摩擦耗散、法向接触耗散和 equality stabilization 分别积分，因此不能仅凭
本次曲线给出严格的逐项能量占比。

## 5. 弧壳在路线中的定位

弧壳不是当前研究的主要优化对象。近期采用以下处理原则：

1. 固定一个足够稳定的仿真接触实现；
2. 不对 capsule 数量开展大规模参数扫描；
3. 不把 capsule 离散损失解释为实体连续外壳的固有损失；
4. 进入真实结构评价时，仍需计入实体外壳的质量、质心和惯量；
5. 只有当离散接触明显妨碍控制研究时，才把弧壳改为更平滑的仿真代理，
   这属于数值模型修正，而不是机器人结构优化。
