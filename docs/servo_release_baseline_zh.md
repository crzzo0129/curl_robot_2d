# 伺服保持 compact 的可变形释放基准

## 1. 实验问题

刚性基准把四个内部关节锁在 compact 角度。当前实验继续使用同一个模型、
相同初始姿态和零初速度，但关闭刚性锁定，恢复真实的当前位置伺服：

- $K_p=10\ \mathrm{N\,m/rad}$；
- $K_d=0.2\ \mathrm{N\,m\,s/rad}$；
- 单关节等效力矩上限为 $\pm6\ \mathrm{N\,m}$；
- 关节目标始终为 compact 角度；
- 根节点人工 damping 关闭；
- 内部关节 damping、地面、摩擦和弧壳保持模型原值。

该实验不是完全被动滚动。位置伺服可以向机器人输入机械能，也可以吸收机械
能，因此必须同时记录电机功率和做功。

## 2. 与刚性基准的主要结果

| 指标 | 刚性锁定 | 真实伺服 |
|---|---:|---:|
| 最大滚动相位 | 284.700° | 280.846° |
| 达到最大相位的时间 | 1.430 s | 1.516 s |
| 相对刚性相位变化 | — | -3.854° |
| 到最大相位机械能变化 | -1.3436 J | -2.0661 J |
| 到最大相位电机净做功 | 0 | -0.9291 J |
| 到最大相位关节 damping 损失 | 0 | 0.0777 J |
| 到最大相位接触/约束残差损失 | 1.3436 J | 1.0594 J |
| 最大关节角误差 | 0.0008° | 14.663° |
| 最大前后足端间隙 | 0.003 mm | 77.147 mm |
| 最大外壳半径峰峰离散 | 0.002 mm | 30.622 mm |
| 最大关节力矩 | 0 | 2.669 N·m |
| 达到 6 N·m 饱和 | 否 | 否 |
| 最大总法向力 | 226.0 N | 224.0 N |
| 总腾空时间 | 0.098 s | 0.102 s |

伺服模型第一次最大相位只比刚性模型少约 $3.85^\circ$，但它在运动中已经
明显偏离圆形。前后两条开链的足端最大分开 77 mm，拟合外壳圆的半径峰峰
差达到 30.6 mm。

## 3. 变形来源

四个 actuator 都没有达到 $\pm6\ \mathrm{N\,m}$ 力矩上限。各关节结果为：

| 关节 | 最大角度误差 | 最大力矩 |
|---|---:|---:|
| front hip | 14.663° | 2.669 N·m |
| front knee | 9.563° | 1.755 N·m |
| rear hip | 11.127° | 1.990 N·m |
| rear knee | 8.743° | 1.600 N·m |

因此当前变形不是“所需力矩超过 6 N·m 后无法保持”，而是有限 $K_p$ 对应
的正常弹性偏差。忽略速度项时，位置伺服近似满足：

$$
\tau\approx K_p(q_d-q).
$$

例如 front hip 的最大误差约为 0.256 rad，仅比例项就对应约
$2.56\ \mathrm{N\,m}$，与记录到的最大力矩量级一致。

## 4. 能量账

到第一次最大相位时：

- 系统机械能减少 2.0661 J；
- actuator 净做功为 -0.9291 J，即电机总体吸收能量；
- 被动关节 damping 消耗约 0.0777 J；
- 剩余接触与约束残差损失约为 1.0594 J。

能量关系按以下形式计算：

$$
\Delta E_{\mathrm{mech}}
=W_{\mathrm{act}}
-E_{\mathrm{joint\ damping}}
-E_{\mathrm{contact/residual}}.
$$

当前固定 compact 目标的位置伺服不是主动滚动策略。它大部分时间在抵抗
关节偏离并吸收运动能量，因此具有额外制动作用。整个 5 s 内 actuator
正向做功 0.910 J、吸收 2.285 J，净做功为 -1.375 J。

## 5. 接触现象

刚性与伺服实验的最大法向冲击和总腾空时间非常接近：

- 最大总法向力：226.0 N 对 224.0 N；
- 总腾空时间：0.098 s 对 0.102 s；
- 最长连续腾空均为 0.010 s。

伺服实验的最大瞬时滑移达到 0.454 m/s，但接触期间的平均力加权滑移只有
0.00307 m/s，与刚性基准接近。这说明存在少量尖峰事件，但不是长期持续
打滑。

## 6. 当前结论

1. 当前 $K_p$ 无法把滚动中的机器人维持为近似刚性圆环。
2. 当前实验没有触及 6 N·m 力矩上限，主要限制是伺服刚度而非峰值力矩。
3. 固定 compact 目标的伺服总体吸收能量，不会形成连续主动滚动。
4. 尽管形状明显变化，第一次最大滚动相位只比刚性基准少约 3.85°。
5. 下一阶段不能只把 $K_p$ 调大；需要先明确控制目标是“保持圆形”，还是
   “允许有目的地变形并移动质心”。主动滚动更可能需要后者。
